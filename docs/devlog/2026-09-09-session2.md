## The instrument: rollout leaves inside the search directive (fork `287e8cca45`)

`-searchpayleaf next|eot|h<N>|end` — `h<N>` = the seat's first quiescent window of a turn > t+N
(the certify horizon), `end` = the copy played to its natural outcome (1 / 0.5 / 0 from the acting
seat; `SearchDirective.leafAfterTurn = MAX_VALUE`, no head call). Every pay answer copy under a
horizon leaf snapshots the certify axes at its stop (`snap` per roll: t_end, ended, life /
creatures / power / hand / lands per seat) and carries its wall (`ms`); the sub row's `leaf` is
the mode name; a rollout-leaf copy gets a 600 s clock (keyed on the leaf turn being past the copy's
turn, so eot keeps 120 s); `-searchclock <s>` names the searched game's wall allowance (default
900). Search-copy / recording only. Built clean; `SurfacesEnumerateTest` untouched.

**Smoke** (3 heuristic games, `-bridgeseats 2 -searchseats 0`, rate 0.3, rolls 2, the e3 ckpt
serving values; end / eot / h2 on the same seeds): every pay answer carries outcomes + snapshots,
0 head calls on the end leaf, ~2–8 s per answer (a heuristic half-game ≈ 2–4 s); wall 437 / 48 /
114 s. `pay_calibration.py` over the three: **12 windows joined, 12 identical, 0 mismatched**;
outcomes and turns identical across arms (the mainline-identity proof holds at smoke scale).

The "bridged certify seat" is the same flags on a bridged arm's seeds (the same ckpt + jar, the
search observational): the pay slot covers the mainline's cast when it is a top-B candidate (B =
the coverage knob). Prep = nothing more to build in the fork; the replay script (the bar0 arm's
seeds under `-search -searchpay B -searchpayleaf end`) waits for the heuristic verdict — if the
target converts on heuristic games the deviation-window read is the confirmation; if not, the
target changes first.
