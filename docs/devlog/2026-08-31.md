# 2026-08-31

## Done

- **The parity witness earned its existence on day one: the first mint
  run is DISCARDED and rerun ([ADR-0088 addendum](../decisions/ADR-0088-grounded-driver.md)).**
  The forensic chain, in order: two lanes tripped the honest-DONE gate
  at ~87–90% rows → the deficit was whole turn-group TAILS clustered by
  game → prefix comparison showed those games diverging at their FIRST
  fork turn, not their last → the full census showed **~97% of ALL
  games diverged** (39/40 lane-2, 37/38 probe1 lane-0), pinned at the
  fork-window turn → the divergence-point census sealed it: **76/76
  divergence points are own-seat cast decisions**
  (`chooseSpellAbilityToPlay` + nested `chooseOptionalCosts`), zero
  opponent decisions, zero other methods.
- **Root cause: serve carry keyed (g, seat) + overlapping store
  ranges.** Probe1's g13 and probe2's g13 are different games sharing a
  carry key; concurrent cross-store replay clobbers carry constantly
  and flips answers exactly where carry is consumed. The solo smoke was
  exact (no collision); generation was always safe (workers take
  disjoint ranges of one store). NOT the GameCopier watch-list class;
  NOT an engine defect; NOT batch-inference jitter (ruled out: the solo
  replay of concurrently-generated games was byte-exact).
- **Fix taken: phased-by-store rerun** (zero code risk — within one
  store lanes partition games disjointly = the generation shape the
  smoke validated). Lanes regenerated 12-per-store, driver runs the
  stores sequentially at concurrency 10; fresh server (the old one's
  carry FIFO held poisoned state); watchd re-registered; session
  monitor re-armed; an early-parity check gates the first hour.
- **Durable fix routed by name (serve hardening): carry keyed by
  connection/channel instead of (g, seat)** — removes the class for
  any future multi-store replay. Standing rule added (never replay
  overlapping-range stores concurrently against one carry-stateful
  server).
- Earlier same-day: two lanes' "dropped turns" accepted (the
  exact-but-truncated parity class coded into the verb) — now
  understood as the SAME defect's milder face (diverged games ending
  early); the acceptance notes were revoked with the run. The class
  stays in the parity verb as a distinct counted outcome.

## Broke / surprised me

- The near-miss chain is worth staring at: without the honest-DONE
  row-count gate (added only after the boot-storm incident), both
  probe2 lanes would have DONE'd silently, `finish` would have minted
  ~900 labels from 97%-poisoned states, the FUND decode leg would have
  re-banked against them, and probe3 would have trained its primary
  decode signal on states the policy never visited — a defect class

  24 hours.

  compute). The phased rerun costs the same wall again (~27 h).
