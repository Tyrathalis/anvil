## Done

- **The review (user: "any decisions before we proceed?")** turned ADR-0112's "the loop does not
  run the search" into four facts: an acted mainline window writes TWO dec + mu records (the
  natural ask, marked realized though never played; the forced single-option re-ask `by: search`
  with the pass masked) — the pre-wiring loader would have trained the first as played and failed
  the tripwire on the second; the search row carries the pick, its behavior log-probability, the
  full distribution, the natural, the margin and the applied class; V-trace's clipped ratio scales
  an acted window's PG down by ≈ the policy's own probability of the pick; and the store dropped
  the rows (ingest keyed labels by a fork-point field). Six decisions, all the recommendations
  ([ADR-0113](../decisions/ADR-0113-m12-loop-wiring.md)): MERGE for the acted-window record; the
  pick-distillation CE on acted windows only; the alloc head's BCE on every searched window with
  tau re-derived per cycle (weighted to the population); guards + tripwire on un-acted windows; the
  recipe + the serving ckpt's tau + a with-lookahead mid-run arm; a two-iteration smoke.
- **Built:** `anvil/training/search_join.py` (pure: the match anchored on the forced dec for acted
  rows, restricted to the search's candidate windows read from the dec's obs — quiescent

  greedy-only serving (the tuck, the surfaces). Fixed: one forward per noise group in the batcher;
  tasks without a sampled head served greedy with no mu record on a sampled server
  (`sampling.sampled_tasks`); model errors print their traceback the first three times per tag.
