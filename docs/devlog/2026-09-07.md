acting; naming to the closeout.

## The ability representation (fork `b0567608938`, then `a0ed9e314b5`)

- `AbilityKey` — `canon(sa)` = host (+ origin), `T:` trigger params, `K:` keyword original,
  `ALT:`/`OPT:`, `A:` api + sorted script params per chain link (AI hints and description keys
  dropped), `D:` the full description; key = SHA-256/16 hex. `"ak"` on every ability-bearing
  option entry and answer (`decPriority`, `peekPriority`, `castPlan`, `Surfaces.optJson`); the
  session emits each key's text once per game as `"abil":[…]` on the dec that introduced it.
  `AnvilRun -abilities <names> <out.jsonl>` enumerates the pool inside a throwaway Game (the
  null-owner UI path left spells and keyword traits out: 1,424 abilities / 484 empty cards; with a
  Game **1,701 cards → 5,148 abilities, 0 errors**; the 6 "empty" names are split-card faces).
  `AbilityKeyTest` (3) passes. Cache: `anvil.encoder abilities` → `abil-cf2ca6ba-qwen3`
  (5,148 × 2,560, Qwen3 rev `5cf2132abc99`) + the description-only control.
- **The frozen probe** (`scripts/ability_effect_probe.py`, `data/runs/build3-ability-probe/`):
  every effect class (32 with ≥ 20 positives) linearly decodable from the canonical-text embedding
  at AUC 0.98–1.00; the description-only control 0.80–0.99; the canonical text adds most where
  the script carries what the sentence does not — ChangeZone destination 0.84 vs 0.68 (majority
  0.32); produced-mana color 0.875 vs 0.909 (majority 0.26). **The auxiliary effect loss stays an
  instrument** (ADR-0105 item 7).
- The second fork commit: the resolving ability's key rides the surface dec as `args.sak` (the
  generator passes the `sa` object; `Surfaces.dec` turns it into the key), and **the serve wire**
  (below).

## The Python side (Anvil `aec7ebd`, records `6f559dc`)

`anvil/policy/surfaces.py` (the option-set fields, shared by loader and featurizer; `AbilityCache`);
`dataset.py` `surf_*` tasks (`args.surf` names the shape) + collate; `AnvilNet._surface_decode`:
the target decoder restricted to the named option set — entity options key on their row, players
on the player key, abilities on host row + the ability-table vector, each + a kind embedding, STOP
= the option count; query = `surf_query([state, src, prev]) + slot`, src = the resolving ability's
vector + shape + method embeddings; masks: padding, picked, STOP closed below min / forced at max.
`surf_query`/`surf_key` start as copies of `tgt_query`/`tgt_key` (load_compat), so priority
windows are byte-identical and the surfaces train freely. Serve: tags `mtg.surface.entity_one` /
`entity_set` (featurize + server, gated on a fitted decoder in the ckpt), Java hooks ask
`selectOne` / the new `selectSet(min, max)` when the seat bridges the tag. **Wire smoke**: 3
self-play games on a small fitted ckpt — 21 bridged surface answers, 21 accepted, 0 poison.

`anvil/training/surface_fit.py`: imitation on the 12 ingested Build 2 arm stores (chained per
store; MultiStore refuses overlapping game ranges), cross-fit by (store, game) hash over 5 folds,
per-shape / per-method held-out agreement with the heuristic. **Fold 0, adapter-only** (shared
decoder frozen): surf_one 0.257 (n 20,647; first-option rate 0.198; tutor/fetch
`chooseSingleCardForZoneChange` 0.232 at 12.4 options), surf_set exact 0.355 (n 6,365) — the
frozen query has no room. **Fold 0 with the role copies** (`surf_query`/`surf_key` trainable,
trunk frozen, 3,492 steps / 2 epochs, 10 min): surf_one **0.306** (tutor/fetch 0.281,
`chooseSingleEntityForEffect` 0.395), surf_set exact **0.476** (discard-from-hand 0.680,
sacrifice 0.805, discard-to-hand-size 0.583, `chooseEntitiesForEffect` 0.198). The two
ability-option callbacks (`chooseSingleSpellForEffect` 0.139, `chooseSpellAbilitiesForEffect`
0.076) sit at chance: these stores predate `ak`, so ability options key on host + kind alone —
the label run's store is the first with keys. The chain (folds 1–4 → read → build) launched 16:20
(`scripts/build3_surface_fit_chain.sh`, watchd `build3-fit`).
