## Pre-build review — four things the code said differently from the draft

- **The schedule carry had never run on a fork completion.** `server.answer` gated SchedServe on a store-indexed `g >= 0`; sched-rollout and mint completions are wire sessions (g = -1). So the ceiling's natural arm and every mint completion played with the slot surface CLOSED (mask-closed play, not "advisory"). The read's baseline — "the same ckpt under advisory serve" — therefore needed the carry engaged on wire sessions: keyed by wid now (`SchedServe._key`), gate opened in the server. User confirmed the reading: advisory = carry on, slot tokens fed, the policy as it plays in generation.
- **The census is self-play** (harness default bridges all seats), so binding on a fork completion must scope to the drilled seat: `--sched-binding forks` latches the seat that opens each wire session (the fork fires at the target seat's MAIN1 priority) and the opponent stays advisory on both sides.
- **Population source.** The draft pinned generation at the baseline ckpt; adopted instead (user, this session): **reuse the ADR-0078 ceiling census** — apples-to-apples with the +14.1pp stratum number, replay parity proven on it, candidate-independent for the whole series. Stratum critic pinned = `d4-critic-fullvis` (the eval critic of record; the two critics split the 583 ceiling turns 234 vs 239 below 0.45).
- **Timing anchored on artifacts, not the draft's "≈ an hour":** the ceiling's stage-2 lanes did 2,720 game-end completions in ~1.2 h on 4 lanes (wall= 3,747–4,996 s). 9,600 + 3,200 context completions ≈ 2–3 h with 6 lanes per side against two servers. User accepted. Resolution: the K=8 binomial floor on the per-window paired difference is 0.25, so 600 windows ⇒ ~1.0pp SE before CRN pairing; a 2.2pp bar sits at ~2 SE — the day-zero read reports the empirical paired SE and K for the terminal read is pinned from it (the M7 forced-branch read's deliverable).

## Done

- **Binding execution at serve** (`anvil/bridge/sched_serve.py`, `anvil/bridge/server.py`): `--sched-binding {off,all,forks}`. The rule mirrors the ceiling's engine executor at the answerable set — (1) land-first at a quiescent main window (masked to lands, decline forbidden, the cast head picks WHICH land); (2) NEXT slot present ⇒ masked to that single candidate (a forced answer: logp 0 by construction, targets/X still the cast head's); (3) NEXT absent at a quiescent post-land main window ⇒ trigger 1 "absent" (the slot failed → revision, never a silent deviation; NOT fired with a stack up or off-main, where an absent sorcery-speed slot is simply not castable yet); (4) otherwise HOLD on spells: pass + non-spell options (abilities/lands stay the executor's). Mask = `ex["cand_allow"]` on the pointer logits (`AnvilNet._pointer_logits`), so the sampled pick, its logp, and the loader's recompute see one distribution. **Two-pass at decode windows under binding:** the emission/revision decode is consumed first (the planner's action at this window), then the answer is taken under the new plan's mask — a MAIN1 emission or an absent-slot revision binds at the window it was made at and never costs the phase. mu row: `sched.bind` (land/cast/hold), `sched.allow` (open candidate indices), `sched.slot`, and `sched.lp` = the emitted schedule's log-prob at decode rows (`AnvilNet._sched_decode_greedy` now accumulates it). Loader (`rl.py`) reconstructs `cand_allow` from `sched.allow`; `collate` carries it (padding closed, maskless items open).
- **Cold-start warm-up** (`ModelBackend.warmup`, default on, `--no-warmup`): 3 synthetic priority windows through the batcher before the port opens (the poison-wave hazard from the ADR-0094 list).
- **The paired strength read** (`scripts/sched_paired_read.py`): `population` (eligible turns per `schedule_sweep.eligible_turns`, scored by the eval critic at the fork window, pinned draw `PAIRED_RNG_SEED` in `sched_pins.py`: 600 at v<0.45 + 200 context at v≥0.45), `run` (two servers — A `--sched-binding forks`, B `off` — both `--ckpt` = the census's generating ckpt for the mainline replay and `--drill-ckpt` = the candidate for the fork completions, the M4 D2.4 dual-policy path; lane scripts per side on the sweep's replay-parity shape; natural-only sched points via a 15-line Java allowance in `AnvilRun.readSchedFile` — armId 0 creates the point with no directed arm, ai=-1 natural runs alone; jar rebuilt, parser only, not game path), `read` (per-window paired dwr over CRN rolls, mean/SE/CI/z, binomial floor vs empirical paired SE, FUND/FLAT/HALT vs `PAIRED_BAR` 0.022, context stratum separate, skip/drift/crash accounting, serve counters per side). Server gained `--counts-out` (the SchedServe counters were only dumped beside a mu file).
- **Population drawn** → `data/runs/sched-paired-pop`: eligible universe 4,084 turn-groups; 1,742 below 0.45; 600 primary (mean v 0.198) + 200 context; 83 of the primary sit in the ceiling's own 600.
- **Generation smoke** (4 games, probe6 iter-5, sampled, `--sched-binding all`, `data/runs/bindsmoke-20260903-110242`, ingested): 1,602 emissions = 1,602 two-pass windows; bind kinds land 71 / cast 863 / hold 1,775; every answer inside its mask; **all 863 forced rows record logp 0.0 exactly and recompute to 0.0 through the loader path** (scratch parity check over the ingested store; worst off-mask recompute delta 0.116 < tripwire tol 0.2, the usual bf16 noise); every emission row carries `lp`; first-window pure-hold 8.8% (probe6 generation 13.3%), mean length 1.65 (1.94); 21 absent-slot triggers.

## Broke / surprised me

- **A latent serve defect since ADR-0090's decode landed:** `sched_slot_pick` argmaxes over `[:, 1:]`, which is EMPTY when a micro-batch's candidate axis is the PASS/STOP slot alone (mulligan, attack, pass-only priority windows in a single-item batch) → `IndexError` → loud decline → heuristic fallback. probe6 iter-5's own server log carries **1,266 of them (685 priority + 349 attack + 92 mulligan + ... fallbacks per 480-game iteration)**; mixed 8-worker micro-batches padded the axis most of the time, so it hid. Fixed (STOP outright when there is no candidate axis). The day-zero read serves both sides with the fix, so the comparison stays symmetric; probe6's telemetry carried ~1.2K heuristic answers per iteration nobody counted.
- The warm-up's synthetic window needed the featurizer's player fields (`life/hand/lib`) and a schema-versioned header; three tries.
- `sched_dev_off_plan` inflated under binding by executor-owned land/ability answers → split into `sched_exec_nonspell`.
