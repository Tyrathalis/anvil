# 2026-08-01 (session 5): Chronicle D3 — the reveal scene v1

## Done

- **Chronicle D3 reveal scene v1 BUILT** (fork `playable` @ `8c2134fdbf`,
  pushed). New `ChronicleRevealScene` (~800 lines) + `ChronicleOpenScreen`
  rework replaces the D2 tap-through placeholder. Per the reveal-UX bar:
  - **Ceremony register:** period wrapper = the set's real booster art
    (`b:` key; starters try `o:` first), drag-to-tear with a shearing top
    strip (fling completes; taps get a wiggle nudge, not a tear), strip
    flies off to reveal the face-down stack; tap-to-flip (scale-X flip
    with back-ease overshoot pop), best-last staging (rarity rank then
    buylist value), "Flip commons ×k" button on face-down runs of 3+,
    full 0.9s buildup pulse+shiver on the staged-last card, first-pull
    glint sweep + NEW badge, revealed mini-row along the bottom,
    long-press CardZoom over revealed-so-far only (no peeking).
  - **Batch register** (starters + Open All ×n): rapid cascade
    (~0.27s/card), hard auto-pause on jackpots (rare+/notable — tap
    resumes), soft 0.7s hold on first-pull uncommons, pack-art
    interstitials between packs, tap-to-pause anywhere; buildup only when
    the pack's last card earned it (36 full buildups per box would kill
    the minute budget).
  - **First-pull semantics:** computed from the acquisition log — a card
    glints iff the oldest log event containing its identity IS this
    opening (collection `isNew` is the binder badge, wrong tool here:
    everything just opened is unseen). Duplicate identities within one
    opening glint once (reveal-order dedupe).
  - **Art preload (D2 backlog folded in):** after `openSealed`, the
    loading overlay holds until every card's image file is local
    (bounded 8s), plus a one-ahead texture pre-touch per flip so the
    cascade never hitches on a disk load.
  - **Sound pass, all stock audio:** shuffle=tear/interstitial,
    flip_card=every flip, draw=buildup, take_shard=jackpot,
    coins_drop=summary; haptics via `HapticEngine` gated on the standard
    vibrate pref.
  - **Summary spread:** scrollable grid with NEW badges, headline (count
    • NEW • buylist total via the pricing service), tap-to-zoom, and
    "Open another"/"Open all ×k" continuation from the same group — keeps
    the 200th-pack loop tight.
  - All pacing constants live in one block atop `ChronicleRevealScene`
    (tear/flip/fly/cascade/dwell/buildup/glint durations) — the D5
    dogfood tuning surface.
