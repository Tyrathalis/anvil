# 2026-07-31 session 3: Chronicle promoted — implementation plan + three design items closed

Chronicle graduates from parked concept to a scheduled playable-branch side
stream. Promotion paperwork per the sketch's own rule
([ADR-0029](../decisions/ADR-0029-chronicle-scheduling.md) +

## Done

- **Chronicle SCHEDULED (ADR-0029).** Playable-branch side stream, sibling to
  the QoL track; M4 keeps the research hours. "Streaming" in the prompt was a
  typo for **upstreaming** — the fork-first/re-cut strategy is the vehicle;
  no new architecture, but it hardened the placement choices.
- **Implementation plan v1** ([chronicle-mvp-plan.md](../design/chronicle-mvp-plan.md)):
  headless services in `forge-gui/.../gamemodes/chronicle/` (Quest precedent —
  headlessness enforced by module structure), screens in `forge-gui-mobile`,
  data in `forge-gui/res/chronicle/`, tests in the desktop TestNG tree,
  Adventure `SaveFileData` persistence. Staging D0 paperwork ✓ → D1 headless
  core (gate: simulated-fortnight test) → D2 screens on `mobile-dev` → D3
  reveal scene → D4 Android spike (parallel-early) → D5 two-week phone
  dogfood + numbers pass → visibility flip (hidden behind a pref until then)
  + Discord courtesy float. Stretch: kitchen table, ownership-legality only.
- **Planning found one genuine design gap: the MVP had no income** (battler
  out + pack-cracking EV-negative by invariant + buylist only recycles ⇒
  currency strictly drains, LGS unreachable). Fix (user): **allowance
  stipend** on the played-day schedule; retires when tournament income
  arrives in stage 3.
- **New standing pins:** day tick fires on **ration collection** (≤1/real
  calendar day, local time + ~4am grace); **seed-integrity invariant** (all
  daily randomness from (run seed, day index, domain); sealed items commit
  contents at acquisition — no savescum rerolls, and stage-2 sealed-supply
  falls out); prestige-proof save schema (run-id + meta split) from day one.
- **Reveal-UX bar DEFINED** (the only D3 blocker): period-wrapper identity
  evolving with the timeline (the reveal object is the set's real booster
  art; foil gloss debuts with the 1999 event), tier-2 player-paced mechanics
  (real animated wrapper-tear — **no 3D pack at first**, user correction —
  tap-to-flip, rare-slot buildup), **both registers day one** (the sketch's
  "bulk UX is late-game" was wrong by one day: the day-one starter is 60
  cards and the MVP LGS sells boxes — ceremony + auto-pause batch both ship),
  harvest + tiny sound pass. Bar statement recorded as D3's done-when.
- **Awards round:** first pass = avatars (scaled crop derivation, living on
  the mode's home page — user-confirmed) + **Chronicle-clipping scrapbook**
  as the trophy surface (completion achievements as newspaper write-ups —
  zero art, un-copyable). Standing sourcing principle: cosmetics derive at
  RUNTIME from card images Forge already downloads; no baked or generated
  assets in the repo (ComfyUI = fork-only experimentation at most).
  Aesthetic north star noted, decision deferred: purposeful-retro lo-fi
  (Shandalar-era period argument; Adventure pixel-art precedent).
- **Famous-card allowlist v0 CLOSED to design:** path-shaping ONLY (endpoints
  are backout-guaranteed; entries must state why generic mechanisms can't
  produce their story); one entry per STORY with event-anchored multiplier
  legs (alt-history drops the event ⇒ legs vanish); backout-consistency rule
  (endpoints include terminal settle multipliers — the two mechanisms can't
  fight); ~12-entry seed (Power Nine, Juzám, Shivan-as-deflation-lesson,
  3-leg Reserved List, LED/Bazaar rediscoveries, Commander/Old School/duals
  groups); **seed + calibrate** authoring (user pin).
- **MVP buylist amended (user pin):** rarity/era-flat PLUS a hand-authored
  **1994-desirability tier table** — which IS the allowlist file's MVP-window
  column, shared work. Fixes the worst dogfood moment (a pulled Lotus selling
  like bulk); EV invariant re-checked against it at D5.

## Broke / surprised me

- Nothing broke (no code). Surprises: the missing-income gap hid in plain
  sight through every prior design round (each layer assumed another layer
  was the income); the batch-reveal problem arrives on day ONE via the
  60-card starter, not at late-game pack volume; the 1994 tier table
  synthesis (MVP buylist need + allowlist seed = one data file); and the
  aesthetic call is secretly a cosmetics-budget call (deliberate lo-fi
  collapses Tier C into Tier B).
