  registration dir — but `_notify` appended real

  per full-suite run since the watchd shipped 08-01; pytest-98 was this
  session's own pre-launch suite run. **Fix: `ANVIL_NOTIFY_SILENT` test
  seam** (sibling of `ANVIL_WATCH_DIR`) in both `anvil_watchd._notify`
  and `notify.notify`; the stdout `NOTIFY:` line still prints so the
  test's assertion surface is unchanged. Applied after the mini-run
  closed (no-tree-edits rule). The directory seam without a
  notification seam was the gap — side-effect seams have to cover ALL
  the side effects.
