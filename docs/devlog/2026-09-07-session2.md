## State review (evening)

Box quiet, tree clean at `0db92ca`, fork at pin `1ac2ec8dc0b`. Evening 1 closed; the label run's
pool ingested. Read for evening 2 (mode):

- **The enumerator gaps account for every mode miss** (2,519 of 12,881 mode answers; label run
  sub rows characterized by `(n, min, max, |natural|)`): 858 windows of "choose three, repeats
  allowed" at n 2 → 2 misses each (no multiset path: a size-2 and a size-1 answer); 266 at n 3
  → the add-one neighbour of an empty natural is size 1; 536 "choose exactly two" windows with an
  empty natural → the same size-1 neighbour. The `SearchDirective.Surface` record traced on
  copies carries no repeat flag, so the fix threads the flag from the callback through the trace
  into the sub row. Four pool cards allow repeats (Eldrazi / Fiery / Mystic Confluence, Season of
  Loss).
- **Finding: the heuristic answers no modes in roughly half of all traced mode windows** — all
  but 12 of 1,136 Confluence windows and all 120 Jitte windows resolve with an empty choice
  (`CharmAi` resets the chosen list, `chooseMultipleOptionsAi` finds no `AILogic$Good` mode, the
  spell resolves doing nothing). A modal spell the network casts frequently fizzles by the
  heuristic's hand; the leak is shared by every network arm in the Build 2 reads. The mode head
  addresses it directly — the first evening whose paired read has a plausible real strength
  effect, not only a "nothing broke" read.
- **No store carries ability keys.** The Build 2 arms and the label run both predate
  `b0567608938`, so the modes of one card are indistinguishable to the model (host + kind). The
  mode imitation and the distillation both need a new pool on the proven jar.
- **The distillation term has no loader, and the join is the design gap.** A sub row lives on the
  mainline window's search row; its surface happens on a copy after the forced option resolves.
  Joining to a mainline surface frame works only when the mainline applied the same option:
  mode 8% of sub rows, entity_one 19%, entity_set 17%.

## Decisions (user, this session)

1. **The distillation state = the copy's surface-window frame captured into the sub row** at the
   directive match (the `peekPriority` pure-snapshot pattern; ~26 frames/game), not the parent
   mainline frame and not the 8% mainline join. Rides the enumerator commit and its forkcheck;
   lands before the keyed pool is generated.
2. **The keyed label run regenerates tonight** (1,000 games) on the evening-1 ckpt with the entity
   surfaces served — the behavior policy of record, trunk frozen at day zero — launched alongside
   the forkcheck off a snapshot jar (write while arms fly, prove after).
3. **The mode serve wire adds a repeat flag** to the bridge's set constraints (proto3 bool,
   backward compatible); Java validates distinctness from the callback's flag.
4. **Enumerator scope**: multisets under repeat, every emitted size inside [min, max]; the
   natural's size ± 1 stays the only size neighbourhood when min < max.
5. **Small routed items ride tonight**: the `mtg.mulligan_tuck` serve mapping, the orchestrator
   raising the worker deadline itself when `-searchsurf` is armed, enumerator tests.

Order: fork commit (enumerator + repeat flag + sub-row frames + `mtg.surface.mode`) → tests +
8-game smoke → forkcheck ∥ the keyed label run overnight → the Python side written while they fly
(`surf_mode` loader with repeats, the decoder's repeat mask, the server's mode answer, the
distillation loader + term) → fits and the paired read tomorrow.
