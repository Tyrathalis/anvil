## Broke / surprised me

- `Bash` resets the cwd after every call: a background `mvn -pl forge-gui-desktop` run from the
  Anvil dir failed with "could not find the selected project in the reactor"; always `cd
  /path/to/forge && mvn …` in the same command. Forge jars must run from `forge-gui/` (res/), not
  `forge-gui-desktop/`. `uv run` from another directory resolves another project's env.
- `canPayCost(effect=false)` is not legality-only: a planeswalker-ultimate coin flip (RNG!), the
  ward `willPayCosts` judgment, a Casualty AI filter — the realizer had been applying all three
  since M1.
- The draw-clock mislabel above (status "won" on a forced Draw).
- A `GameCopier` copy resumes only at the ACTIVE player's priority, so search windows are the
  active seat's quiescent main-phase windows — consistent with the ADR-0098 fork points.
