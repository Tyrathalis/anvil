# 2026-08-07 — Otag embedding probe

## What was done

Added Scryfall Tagger functional-tag (`otag:`) support to the embedding
pipeline and measured before/after neighbor drift for both text-embedding
models.

### New files

- `anvil/encoder/otags.py` — curated functional-tag taxonomy, Scryfall
  `otag:<tag>` fetch/caching, frequency clearing, and per-card multi-hot/tag
  output. Uses only stdlib (`urllib`) so no new dependency.
- `scripts/card_neighbors.py` — record top-k cosine neighbors for any
  `.safetensors` embedding cache.
- `scripts/compare_neighbors.py` — before/after Jaccard drift, unchanged
  rate, and top movers.

### Modified files

- `anvil/encoder/cardtext.py` — `render()` and `pool_texts()` can now append
  functional tags to the embedding text.
- `anvil/encoder/__main__.py` — new `--otags`, `--otag-min-cards`,
  `--otag-top-k` flags; embedding stem gains `-otags` suffix so baseline and
  otag caches don't clobber each other; device auto-selects cuda/mps/cpu.

## Findings

Verification by `diff` shows the neighbor files differ for both models.

| model   | unchanged neighbor sets | mean Jaccard | median Jaccard |
|---------|------------------------:|-------------:|---------------:|
| bge-m3  | 32.0%                   | 0.691        | 0.667          |
| qwen3   | 21.7%                   | 0.575        | 0.667          |

Top movers look semantically correct:
- `Basalt Monolith` moves from generic artifacts to mana rocks.
- `Cabal Ritual` moves from random black cards to ritual effects.
- `Drown in the Loch` moves to counterspells.
- `Aang, Swift Savior` (Universes Beyond) moves from lore/IP neighbors to
  functionally similar white/blue flash creatures.

## Interpretation

Injecting otags into the embedding text produces a strong, measurable signal
in both embedding spaces. It is a cheap probe; the design-doc path (otags as
structured features fused in `CardEncoder`) requires retraining any model
whose `CardEncoder` weights are frozen, because the feature dimension changes.
The current code leaves that path open: `anvil/encoder/otags.py` can output a
multi-hot matrix that `pool_features()` could consume in the future.
