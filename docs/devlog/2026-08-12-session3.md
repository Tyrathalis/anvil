## Design deviations recorded

- **3-arm campaign on the era jar** (ADR-0054 pinned 2 arms): the fork's
  `-forceseq` hard-codes natural/hold/act, and a jar change mid-era is not
  worth ~0.5h/iter — the natural arm rides as a free validity read AND
  supplies wr_nat for C2a. A 2-arm trim flag queues for the next boundary
  window. Cost at P=100/K=16 ≈ 1.4–1.5h/iter vs the ADR's ~1h.
- **Both phases replay mainline argmax** (drill machinery constraint —
  `--sample-forks` pins argmax by design), so labels and windows describe
  the same fork states; replay drift (~1–2% class) = bounded label noise,
  unjoined points drop.
- **w_seq calibration uses loss magnitude as the gradient-mass proxy**
  (the pin said "10% of policy-gradient mass"); the calibration record
  keeps every input so it can be re-derived if the proxy misleads.
