## Done

- **`grindstone select` (the sweep's design consequence made mechanism):**
  per-game drill fork-turn selection from K-rollout ground truth.
  - Rule: **latest labeled fork turn whose rollout winrate lands in the
    trainable band [0.25, 0.75]** — later = closest to the decision
    error and cheapest completions; band = outcome variance exists.
    Fallback: latest turn *above* the band (position winnable early —
    converting won positions is still a drill). Excluded if nothing
    clears the floor anywhere (the luck-locked profile).
  - Label sources are dirs holding `drills.jsonl` (map, sweep arms),
    merged **later-supersedes at the same fork turn** — re-measures
    listed after selection-time labels, per the D2.4 lesson.
  - **Evalset holdout subtracted here** — `select` is the boundary
    where training lists are built; `--holdout` reads the evalset's
    `held_out` membership.
  - Output rows = curation rows + `drill_turn`/`sel_rule`/`sel_wr`, and
    `plan` gained `ANCHOR_FIELD["selected"]` so `plan --anchor selected`
    consumes the selection with zero further changes.

## Same session, part two: fork-session ingest (fork `66fa3fe45e`, Anvil `add7326`)

- **The design-shaping fact, established by reading before building:
  fork sessions were wire-only by construction** (M2 D1's "without
  polluting the corpus") — drill completions left NO stored
  trajectories, and three latent hazards had to be solved together:
  (1) fork wire headers carried `g=-1`, so sampled-μ records from all
  completions would have collided on (g,s); (2) all K completions of a
  fork point announced the PARENT seed, so seeded Gumbel noise would
  have been identical across them; (3) the serve path seeds each fork's
  history ring from the parent game, which a loader-side reconstruction
  from the fork's own frame can never recover.
- **Fork side (`-forkobs`, off = byte-identical):** fork sessions
  stream to a SEPARATE `obs-forks.zst` (the mainline frame is open
  while forks run — no interleaving), each completion a store frame of
  its own with a synthetic unique id `(g*100+fp)*100+r`, fork
  provenance in the header (`{pg,fp,r,tt}`), the completion's OWN
  rollout seed announced to the bridge (kills hazards 1+2), and **dec
  records carrying the serve-time wire hist verbatim** (kills hazard 3
  — it is literally the composite the bridge sends). End records carry
  the driver-computed winner (same tally that feeds labels.jsonl).
- **Ingest `--forks`:** consumes fork frames only — **drill mainlines
  never enter training ingest** (the D2.2 pseudo-winner hazard, now
  enforced by construction); games.jsonl synthesized from fork end
  records + header names (winner_seat parses 1-based seat names — a
  fixture initially written 0-based caught that assumption);
  per-fork-point aggregates cross-checked against labels.jsonl (two
  paths, one tally); manifest tagged `source: drill-forks` +
  `drill: {parent_run, drill_file, labels_check}`.
- **Loaders:** rl.py and dataset.py (critic path) prefer stored `hist`
  when a dec carries it, else reconstruct as before.
- **Smoke end-to-end (2 drills, K=8):** 16 fork frames (15 completions
  + 1 crash frame; 1 copy-crash correctly frameless), ingest clean,
  labels cross-check 2/2 agree, castplan validate OK over 9,181
  windows, **first window featurizes with 8/8 parent-ring history rows
  where in-frame reconstruction sees zero** — the parity point proven.
  ~78 KB/game at 94.7×. Outcome deltas vs selection-time labels: one
  completion flipped per game — the known wall-clock drift class at
  near-tie windows (the games sit at sel_wr ≈ 0.3 by construction).
