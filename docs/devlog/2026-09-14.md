# 2026-09-14 — the custom-pool quickstart + the Discord limited thread

## What was done

- **Discord (#ai-plotting, 09-13 → 09-14):** Dan B (statisticaldrafting.com) wants 17lands-style
  draft statistics from self-play before a set reaches Arena; ran 30K HOB games on the stock bot
  (blue loses, Smaug top common — the "Forge is bad at instants" bias at colour level). The thread
  (Shedletsky, LordOfThePigs, talor, chrismaghuhn) converged on what the survey doc already said:
  pilot bias leaks into card rankings, paired seeds, win/loss as the only reward. Two corrections
  banked in the [survey doc](../design/discord-ai-plotting-survey.md): 17lands' replay data DOES
  carry per-turn human actions (no decision context) — the first human-play corpus for a
  Forge-supported format, a Mentor calibration lead; and the repo was linked publicly with no
  newcomer path.
- **The quickstart** ([quickstart-custom-pool.md](../design/quickstart-custom-pool.md), linked
  from the README): fork build → pool from your own decklists (the `pauper` slot as the generic
  Constructed pipeline) → embed → heuristic corpus → BC → paired read → self-play → read, with
  Kryptic's settings as the defaults and the cost table.
- **The gap it exposed, fixed:** `anvil.training.selfplay` and `scripts/final_read.py` hard-coded
  the Commander pool (`--pool` with no `--pool-format`, no `--format` to the harness), so a
  Constructed pool could not go through the loop without a patch — Kryptic must have carried one.
  Both now take `--format` / `--pool-format` (defaults unchanged: Commander / dc; pinned into
  `loop_config`). `anvil.pool build --main-size N` on the Constructed slot for 40-card decks
  (parser + manifest only; untested in play — the guide says so).
- **Verified:** a 2-game launch with `--bridge-seats 2 --obs` (no seat bridged) records dec/ret
  for every callback (2,425 / 2,268) and ingests with `--verify` clean — the corpus recipe the
  guide gives. Pool/selfplay/final_read tests 30 pass.
