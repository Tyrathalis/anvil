## The pings weren't real — found by the user asking "have you actually gotten any?"

- **Zero driver-narration lines reached driver.log in 36h**: a detached
  Python driver's stdout to a redirected file is BLOCK-buffered; every
  `===== iteration` marker sat in memory while subprocess output (own
  fds) interleaved normally. The log-tail monitor's filter had nothing to
  match — silence indistinguishable from health. Terminal events were
  covered regardless (exit flushes + pgrep watcher + notify-send hook
  bypasses stdout), and the exit flush at the halt delivered the entire
  36h narration in one batch, confirming the diagnosis exactly.
- Fixes: (1) mid-run telemetry now watched from `monitor.jsonl` (driver
  writes it line-buffered — verified live on iters 14–18 including the
  guard event); (2) driver `sys.stdout.reconfigure(line_buffering=True)`
  (merged); (3) memory note updated — **verify a watcher fires on a real
  event before trusting it**.
- The driver-notify rider worked at the halt (desktop notification) +
  mobile push sent.
