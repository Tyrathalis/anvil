## Broke / surprised me

- **The unfixed merge crashed 19 of 500 forkcheck games.** One upstream bug, six days old, in new AI code that runs with Monte Carlo off. The forkcheck's precon pair happens to hold a card with the throwing shape; the pool holds none.
- **I first told the user five pool cards hit the bug's silent form. It is two** (Sram, Senior Edificer and Ral, Monsoon Mage). My scan matched `SpellCastOrCopy` triggers, which that code does not read.
- **Five fork tests pinned heuristic weaknesses.** They failed because upstream fixed the weaknesses. A test that asserts what the heuristic cannot do breaks at the next merge.
- **The served smoke's largest callback change was a loop, not a rate.** `chooseTargetsFor` fell from 0.6 calls per game to none. The loss was real (upstream bypasses the callback for copies), but 72% of the old calls were Chain of Smog copies in a few games. After the fix the smoke shows three windows in 200 games, which confirms the path and says nothing about the rate.
- **The AI's wall-clock deadline fired four times in the unfixed jar's first pass** on a near-idle box, and the repeat still matched. It did not fire in the fixed jar's passes. It has not been read under load.
