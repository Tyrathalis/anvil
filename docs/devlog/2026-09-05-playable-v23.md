- **v24: the Android res refresh had never run between versionCode bumps**
  (`fe86deded9`). The user reported the v23 APK installed with no second
  data download. Diagnosis: the Android startup fallback returns early when
  the APK's `versionName` equals the last-synced version, before the build
  stamp comparison and the priced res delta. `versionName` is the Android
  manifest's, and the `android-debug` profile's `manifest-merger` had no
  `manifestVersionName` (the release profiles do), so every fork APK since
  v16 was bare `2.0.15-SNAPSHOT` (aapt-confirmed on the 08.23 and 09.05
  builds). v16's 2.0.14→2.0.15 bump opened the gate once; v17–v23 closed
  it. Same defect as the 08-23 missing `rivals.txt`. Fix: dated versionName
  in the debug profile (versionCode now derives from it, 200001500 →
  200150905), a build-stamp guard on the gate, `.xcf` skipped in the
  Android diff (13 manifest entries assets.zip never ships). Desktop jar
  rebuilt too (shared mobile code) so the published `build.txt` stays the
  desktop stamp. Post-publish routine in full.

## Broke / surprised me

- `mvn -rf :forge-gui-mobile` cannot resume a `-pl … -am` reactor build:
  the sibling modules are never installed, so resolution falls through to
  jitpack and fails. Re-run the full command; it is incremental anyway.
- Checkstyle (unused import) fails the build after a mechanical conflict
  resolution — the `Matrix4` import outlived its last use in `Forge.resize`.
- `xdotool click` on the libGDX mode menu did not register at the coordinates
  I guessed; irrelevant to this release (the resize captures were the point)
  but the harness still owes a reliable "enter Classic Mode" step.

- The Android delta path (item 2's mobile half, built 08-2x) had never
  executed on a phone: the gate in front of it was always shut. Its first
  live run is the v24 boot.
- The merger's `versionCodeUpdateFromVersion` turns `MM.dd` into the low
  digits of versionCode — fine until a year rollover without an upstream
  2.0.15 bump, when the next build would read as a downgrade. Upstream has
  the same property; they bump often enough never to hit it.
