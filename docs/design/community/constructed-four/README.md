# Kryptic's constructed-four pool (Discord #ai-plotting, 2026-09-17)

**Doc status:** community asset · read 2026-09-17

Four mono-coloured 60-card decks (Blue Tempo, Green Stompy, Red Aggro, White Weenie) and the
matchup workbook from Kryptic's second Anvil run (`constructed-four-rl-4000`: 8,000-game BC →
40 V-trace iterations × 2,000 games; arms 4,000–8,000 games every 5–10 iterations; a 40,000-game
heuristic-vs-heuristic reference matrix). The read and the command line are recorded in
[../../discord-ai-plotting-survey.md](../../discord-ai-plotting-survey.md) (the 09-17
follow-up). The `.dck` files are Forge deck files (`[metadata]` / `[Main]`, `count name|set|art`);
the workbook's README sheet documents its formulas (Wilson CIs; crashes count as non-model wins).
Kept as the second smoke pool for [quickstart-custom-pool.md](../../quickstart-custom-pool.md).
